<h3 align="center">Powered by curiosity (and too much coffee).</h3>

Most of my day is pandas, DuckDB and SQL — taking spreadsheets and half-documented databases and turning them into tables someone can actually query without asking me first. I care about the unglamorous parts: schema choices, idempotent loads, and pipelines that fail loudly instead of quietly. Lately I've been leaning on DuckDB for local analytics because it lets me test the same SQL I'll ship.
